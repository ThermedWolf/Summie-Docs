# Contributing to Summie

Thanks for your interest in contributing to Summie-Docs! Contributions of all kinds are welcome, including bug reports, feature ideas, documentation improvements, and code changes.

## Before contributing

Before opening an issue or pull request, please check whether someone has already reported or discussed the same thing.

For larger changes or new features, consider opening an issue first so the idea can be discussed before you spend time implementing it.

## Reporting bugs

When reporting a bug, please include:

* A clear description of the problem
* Steps to reproduce it
* What you expected to happen
* What actually happened
* Your operating system and relevant environment details
* Screenshots or logs where useful

Please avoid including sensitive or personal information in issues.

## Suggesting features

Feature requests are welcome. Please explain:

* What you would like to change
* Why the change would be useful
* How you would expect it to work

## Pull requests

When submitting a pull request:

* Keep changes focused on one issue or feature where possible.
* Clearly describe what your pull request changes.
* Explain any important design decisions.
* Make sure existing functionality is not unnecessarily broken.
* Update documentation when your changes require it.
* Test your changes before submitting the pull request.

Please don't be discouraged if changes are requested during review. Code review is intended to improve the project, not to criticize contributors.

## Development

1. Clone the repository.
2. Install the required dependencies with `npm install`.
3. Start the development environment with `npm start`.
4. Make your changes and test them locally.

## Code style

Please follow the existing code style and conventions used throughout the project.

If the project has automated formatting or linting tools, run them before opening a pull request.

## Questions

If you're unsure about something, feel free to open an issue or discussion before making a larger change.

## Code of Conduct

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
