# Security Policy

## Supported Versions

Only the latest version of Summie is currently supported and receives security updates.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Summie, please report it using **GitHub's Private Vulnerability Reporting** feature.

Please do not report security vulnerabilities through public GitHub Issues, as this may expose the vulnerability before it can be addressed.

When reporting a vulnerability, please provide as much information as possible, including:

* A description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant screenshots, logs, or examples

Security reports will be reviewed and addressed as soon as possible.

Thank you for helping keep Summie secure.
